🚀 Hosting & Synchronisations-Anleitung

FerroStash bietet zwei flexible Hosting-Möglichkeiten für deinen Clan:

Option A (Kostenlos via GitHub Pages)

Serverless mit GitHub Pages

  1. Erstelle ein neues GitHub Repository (z.B. mein-clan-vault).
  2. Lade den Inhalt des web/ Ordners in dieses Repository hoch.
  3. Aktiviere unter Settings -> Pages den Branch main.
  4. Erstelle einen GitHub Personal Access Token (PAT) mit Repo-Rechten.
  5. Trage im Minecraft-Spiel (Taste O) im Tab Clan & Sync Repo-Name & Token ein.
  6. Fertig! Das Spiel pusht Updates via GitHub API und deine Seite ist weltweit erreichbar.
Option B (Eigener Server / VPS)

Self-Hosted mit Node.js & Docker

  1. Kopiere den web/ Ordner auf deinen Server / VPS.
  2. Starte mit Docker: docker compose up -d oder mit Node: npm install && npm start.
  3. Der Server lauscht auf Port 3000 mit REST API Endpunkt POST /api/sync.
  4. Trage die Server-URL in deiner config/ferrostash/config.json ein: "http://dein-server:3000/api/sync".
  5. Alle Clanmitglieder mit der Mod synchronisieren ihre Kisten nun in Echtzeit!

🎮 In-Game Mod Schnellstart

1. Kopiere ferrostash-1.0.0.jar in deinen Minecraft .minecraft/mods Ordner.

2. Benötigt: Fabric Loader (0.19+) und Fabric API für 26.2 mit Java 25+.

3. Drücke im Spiel jederzeit Taste "O", um das Lagermenü zu öffnen und Kisten-Wegpunkte zu aktivieren!
